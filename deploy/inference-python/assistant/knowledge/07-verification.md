# 检测结果核验
tags: 核验, 复核, 误判, 自查, 过程材料, 申诉

## 为什么拿到报告要先「核验」而不是直接改

**结论**：检测结果是「疑似标记」，会误判——第一反应不是改，而是核验「这几段到底是不是我写的」。

- 任何检测器都会误判，国际主流产品准确率也只有八成多、每十篇就有一两篇假阳
- 高度规范化的学术写作最容易中招
- 数字是参考信号，你的写作过程才是真相

**平台对应**：报告的 `calibratedProb` + `confidenceInterval` + `sourceLabel` 是核验的三个入口。

## 自查三步：拿到报告先看什么

**结论**：看高风险段 → 看区间 → 看溯源，三步走完再决定申诉还是修改。

- ① 找风险最高的几段（红色、概率高），逐段回忆是不是自己写的、有没有参考过 AI 输出
- ② 看置信区间：跨过红线、或整体贴着红线，是边界情况
- ③ 看溯源标签：报告标注的「疑似来源」和你实际用过的工具对得上吗？对不上常是误判

**平台对应**：`topRiskParagraphs`（高风险段）、`confidenceInterval`（区间）、`sourceLabels`（溯源分布）。

## 哪些情况更像是误判

**结论**：教科书式正规学术体、非母语、被润色过、短段落，这四类更容易被误判。

- 写得特别「教科书」的正规学术体
- 非母语写作者
- 用过润色工具改过的文字
- 约 120 字以下的短段落

**平台对应**：短段落有 `warnings`；见「为什么规范的学术写作容易被误判」。

## 写作过程材料是核验的关键证据

**结论**：能证明写作过程的材料越多，核验越有说服力。

- 带时间戳的草稿和修订记录
- 实验数据、文献笔记
- 和导师讨论的聊天记录
- git 提交历史

**平台对应**：申诉时一并提交，比「我真的是自己写的」有用得多。

## 平台怎么核验：人工复核流程

**结论**：申诉后进入人工复核，复核看「原文 + 表层特征 + 你的材料」三样。

- 状态：待处理 → 处理中 → 已回复
- 复核依据：段落原文、表层特征证据（句长节奏、用词丰富度、套话连接词）、你的材料
- 结论在「我的反馈」查看

**平台对应**：工具 `explain_paragraph` 返回的表层特征就是复核看的证据之一。

## 核验的边界与结论

**结论**：复核能纠正明显误判，不能把真 AI 内容「洗白」；平台不直接改报告结论。

- 三种结论：维持原判定 / 认定申诉合理 / 补充材料
- 认定合理 ≠ 改你报告数字，而是记入模型改进清单
- 平台无「教师 override」，运营只能查看 + 回复

**平台对应**：见「申诉与人工复核流程 · 复核结论有哪些」。

## 核验之后怎么做

**结论**：维持判定就重写；认定合理就用现有报告；过程材料建议长期保留。

- 复核维持判定：和导师沟通后，按学校规定用自己的话重写相关部分
- 认定申诉合理：以反馈回复为准，报告数字本身不变
- 过程材料继续留：既是答辩底气，也是将来再次核验的证据

**平台对应**：反馈结果在「我的反馈」页；重写后可重新上传检测对比。
