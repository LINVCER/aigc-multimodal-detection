# AI 智评：论文质量与合规的大模型评审

> 2026-10 · 状态：方案，待拍板三项（§9）后开工。
> 关联：`202610-paper-assistant-agent-research.md`（小白 agent）、`202610-explainable-evidence-plan.md`（证据）、`MODEL_RESEARCH_TEXT.md`（LLM-as-judge 调研）。
> 定位铁律：**AI 参考意见，非权威评审**；辅助作者自检 / 导师预审 / 期刊初筛，不下终审结论。

## 0. 为什么做

- 和 AIGC 率互补：一个查「是不是 AI 写的」，一个评「写得好不好、合不合规」。把工具从「查 AI」扩成「投稿前自检」，更高频、更愿付费。
- 技术几乎零新增：复用现有小白（OpenAI 兼容 LLM + 工具回调 + 知识库）、`TextProcessor` 切分、知识库检索。
- 竞品已在做（见 §2），是强差异化留存点。

## 1. 产出形态（对齐参考图）

- **综合评阅等级**：A/B/C/D + 一段综合评语。
- **分维度评审**：
  - 研究质量：研究方法 / 研究内容 / 研究结论（A/B/C 等级）。
  - 底线合规：题文一致性 / 事实准确性 / 意识导向合规性（见 §7 的边界处理）。
- **评议要素报告**：逐要素下钻，每项给等级 + 依据 + 可点跳转到对应段落。

## 2. 现状与竞品（2026，WebSearch 核实）

| 来源 | 要点 |
|---|---|
| AAAI 2026 | 已试点 AI 审稿，24h 审完 2.3 万篇，单篇 < $1 |
| ReviewGrounder | rubric 引导 + **两阶段：起草 → 证据核查**，当前最佳实践 |
| CycleReviewer | 分数预测比单个人类审稿人平均误差低 26.89% |
| 中文商用 | 查重降重工具开始加「智评/综合评价」，主打「合规无幻觉」 |

**可靠性结论（必须设计进去）**：LLM 评审有位置偏差 / 光环效应 / 版本漂移，前沿模型偏差测试错误率 > 50%；且**倾向给又短又浅的论文高分**；「事实不准」这类具体指控**常是幻觉**。改进手段：rubric + CoT + few-shot（可靠性 +85%）、证据核查两阶段。

## 3. 评议要素与评级

每个要素定 rubric：评分锚点（A/B/C 各自的判据描述）+ 需要的证据类型。

| 维度 | 要素 | 评什么 | 证据来源 |
|---|---|---|---|
| 研究质量 | 研究方法 | 设计严谨性、抽样、信效度、统计规范 | 原文方法/实验段 |
| | 研究内容 | 文献梳理、变量操作化、论证层次 | 原文引言/相关工作/分析段 |
| | 研究结论 | 结论与数据一致、贡献与局限 | 原文结果/结论段 |
| 底线合规 | 题文一致性 | 标题 ↔ 内容是否对得上 | 全文 |
| | 事实准确性 | 具体数字/常识/引用是否站得住 | **证据核查**：知识库/检索回验 |
| | 意识导向合规性 | 见 §7，初期只做风险提示 | 规则 + 人工 |

综合等级 = 各维度加权聚合（权重可配，合规维度为「门槛项」而非加分项）。

## 4. 两阶段流程（ReviewGrounder 式，抗幻觉）

```
论文全文 → TextProcessor 切分 + 定位各章节
   │
   ▼  阶段一：起草（LLM + rubric + CoT + few-shot）
   逐要素出初评等级 + 评语草稿 + 「待核查声明」清单（事实/数字/引用类）
   │
   ▼  阶段二：证据核查（只核关键指控，别裸口下结论）
   事实/数字 → 回查知识库 / 检索核验；引用 → 核对；题文一致 → 全文比对
   核不住的指控降级为「存疑」，不写成「不合格」
   │
   ▼  聚合：综合等级 + 分维度 + 逐要素（依据 + 段落锚点）
```

关键：**没有证据支撑的负面结论一律降级为「存疑/建议自查」**，不写成「不通过/不合格」。

## 5. 复用现有能力

- LLM 层、工具回调、知识库检索：复用 `deploy/inference-python/assistant/`（小白）。
- 论文切分、非正文过滤：复用 `TextProcessor`。
- 证据核查的检索：复用 `search_knowledge` + 可选外部检索。
- 新增一个 agent 任务 `review_paper`（独立于对话），输入 taskId（已检测任务）或直接传全文。

## 6. 接口与数据

| 接口 | 用途 |
|---|---|
| `POST /api/v1/review/submit` | 提交评审（taskId 或文件），异步返回 reviewId |
| `GET /api/v1/review/{id}` | 评审结果：综合等级 + 分维度 + 逐要素 + 评语 |

表 `paper_review`：id、task_id、overall_grade、summary、dimensions(JSON)、model_version、status、created_at。
不存论文全文（复用 detect_task 已有的）；评语与等级可存。

## 7. 风险边界（决策项，不展开）

- **意识导向合规性**：初期**只做「风险提示标记 + 依据」，不做「通过/不通过」定性裁决**（误判责任过重）。是否上、谁担责，见决策三。
- **所有结论挂「AI 参考意见，非权威评审，以期刊/学校为准」**。
- **负面指控必须带证据**，核不住就降级为「存疑」。
- 文案沿用 style-prompt：不代写、不改写，只给方向。

## 8. 分期

| 期 | 内容 |
|---|---|
| 一 | 研究质量三要素（方法/内容/结论）+ 题文一致性；rubric + 两阶段；结果页 + 逐要素下钻 |
| 二 | 事实准确性（证据核查强化）；评语可追问小白 |
| 三 | 合规风险提示（若决策三为做）；导师/期刊批量评审入口 |
