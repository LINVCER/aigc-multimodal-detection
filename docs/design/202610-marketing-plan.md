## 1. 竞争格局与我们的位置

| | 知网 / 维普 / 万方 | GPTZero / Turnitin | 灰产「降写」 | **我们** |
|---|---|---|---|---|
| 权威性 | 高（学校认可） | 高（英文主流） | 无 | 中（需建立） |
| 可解释性 | 低（只给 AI 率） | 中（句子色码） | 无 | **高（逐段解释 + 溯源）** |
| 溯源哪家 LLM | ❌ | ❌ | ❌ | ✅ |
| 合规性 | 高 | 高 | **低（灰色违法）** | 高（明确不代写） |
| 价格 | 贵（按次收费） | 贵 | 乱 | 免费（课题阶段） |

**差异化三角（竞品无人同时具备）**：`溯源（哪家 LLM）` × `可解释（为什么像 AI）` × `合规原创引导（自己改不代写）`。

## 2. 目标用户画像

| 画像 | 场景 | 核心诉求 | 情绪 |
|---|---|---|---|
| **毕业班学生**（本科/硕士/博士） | 交论文前自测 | 「我会不会超线？超了哪段？」 | 焦虑 + 怕误判 |
| **被误判的原创者** | 收到「疑似 AI」报告 | 「这段明明是我写的，怎么证明？」 | 愤怒 + 无助 |
| **低年级学生** | 写课程论文 | 「怎么避免写得像 AI？」 | 困惑 |
| **导师/辅导员**（潜在 B 端） | 审学生论文 | 「谁写的、哪段可疑」 | 责任压力 |

**主攻第一、二类**——他们是当前最痛、最愿意传播的人群。

## 3. 定位与差异化主张

**核心定位**：

> **「不只告诉你 AI 率，还告诉你为什么、哪段、怎么改（自己改）。」**

一句话 slogan 候选：
- 「看得懂的 AI 检测」
- 「被判像 AI？先别急着花钱降——看懂再改」
- 「知道像哪家 AI，才知道怎么不像」

**三条价值支柱**：
1. **可解释** —— 逐段给出「为什么像 AI」+ 溯源哪家 LLM（对抗「只给分数」）。
2. **救误判** —— 申诉材料 + 写作过程证明指引（对抗「原创被判 AI」焦虑）。
3. **引原创** —— 只给方向不改写，帮你「自己重写」而不是「帮你洗稿」（对抗灰产，建立信任）。

## 4. 营销方向（四个候选，附推荐）

### 方向 A · 误判救助（⭐ 推荐，痛点最痛）
- **切入**：抓住「原创被判 AI」的愤怒情绪。
- **内容**：「原创论文被判 AI？先做这 3 件事」/「为什么你手写的论文会被判 AI（附申诉模板）」。
- **转化**：免费检测 → 溯源报告 → 申诉材料指引。
- **理由**：这是权威平台和灰产都覆盖不到的空白，且自带传播性。

### 方向 B · 可解释性降维
- **切入**：「别的平台只给你一个数字，我们给你逐段解释」。
- **内容**：报告解读教程、溯源可视化、段落热力科普。
- **理由**：技术差异化最直观，适合知乎/CSDN 等理性渠道。

### 方向 C · 合规原创引导（长期信任）
- **切入**：「不帮你洗稿，帮你写得更像自己」。
- **内容**：学术写作规范、降 AI 率的「正当姿势」（重写而非套话）。
- **理由**：建立长期品牌，拉开与灰产的合规距离，符合课题定位。

### 方向 D · 场景细分（阶段二）
- 研究生论文 / 职称评审 / 自媒体内容，按场景定制内容与产品页。
- **理由**：扩圈用，等 C 端跑通再做。

**推荐组合**：**A 打爆点（获客）+ B 建认知（说服）+ C 立品牌（留存）**，D 缓一缓。

## 5. 渠道与内容策略

| 渠道 | 打法 | 内容形式 | 优先级 |
|---|---|---|---|
| **小红书 / 抖音** | 情绪 + 场景化：误判、降 AI 焦虑、毕业季 | 短视频、图文笔记 | ⭐ P0 |
| **知乎 / CSDN** | 理性 + 权威：AIGC 检测原理、溯源、误判机理 | 长文、专栏 | ⭐ P0 |
| **微信社群 / 校园 KOL** | 口碑裂变：毕业班群、论文互助群 | 邀请码、免费额度 | P1 |
| **SEO / 官网** | 「论文 AI 率检测」「AIGC 检测免费」等长尾词 | 工具页、落地页 | P1 |
| **B 端（导师/教务处）** | 权威背书：溯源 + 可解释报告 | 演示、白皮书 | P2 |

**内容黄金公式**：`痛点场景（焦虑）→ 为什么这样（原理/溯源）→ 怎么办（平台免费工具）`。

## 6. 增长漏斗与 KPI

```
曝光（内容/SEO） → 首次检测（免费无门槛） → 报告可解释性留存 → 分享/复检 → 口碑
```

| 阶段 | 指标 | 目标（首月） |
|---|---|---|
| 曝光 | 内容浏览量 / 搜索排名 | 10 万次曝光 |
| 转化 | 首次检测完成率 | 5% 曝光 → 检测 |
| 留存 | 复检率 / 助手使用率 | 30% 复检 |
| 传播 | 分享率 / K 因子 | ≥ 1.1 |

## 8. 需要你拍板

1. **营销方向**：按推荐「A 误判救助打头 + B/C 跟进」？还是你另有偏好的切入角度？
2. **是否先补一个获客刚需**——竞品 gap 文档里的 **P0 PDF 报告导出**（学生要交学校/申诉要证据，没有它很多转化链路走不通）——营销起盘前要不要先落地？
3. **KPI 口径**：课题阶段以「曝光 → 首次检测 → 复检」为北极星，还是你有具体数字目标？
4. **是否现在产出第一批内容**（小红书笔记 + 知乎长文各 5 篇的选题清单 + 首篇成稿）？还是先把产品获客链路补齐再动内容？
