## 提示词（以下内容整体复制使用）

你是一名资深产品设计师，具备设计系统（Design Tokens / Atomic Design）与可访问性工程（WCAG 2.1）实践经验。现对「知源」论文 AIGC 检测系统 Web 端执行主题风格优化。目标用户为在校大学生，产品定位为**兼具专业可信度与亲和力的论文检测工具 + AI 助手「小白」**——视觉需传达「可靠的论文搭子」，而非冰冷工具或儿童化玩具。请在既有方案基础上完成以下任务。

### 1. 产品上下文

- 产品能力：论文 AIGC 检测四问——AI 率数值、可疑段落定位、逐段归因解释、修改建议；AI 助手「小白」提供报告解读对话；
- 用户画像：本科 / 硕士 / 博士在校生；高频场景：DDL 前自查、导师返修、答辩前检查；
- 品牌资产：吉祥物「小白」——白色球形主体、青绿触角顶球、耳机侧耳、青色星形高光大圆眼、粉腮红（源文件 `web/public/xiaobai.png`）。

### 2. 设计约束（不可协商项）

| # | 约束 | 参数与判定标准 |
|---|---|---|
| C1 | 主色唯一性 | 主操作色仅 `--ai-700 #0F766E`（源自小白形象特征色）；`#14B8A6` 仅用于装饰渐变与底色，禁止承担正文文字对比 |
| C2 | 背景体系 | 页面底 `#FAF9F6`（暖白）、卡片 `#FFFFFF`、区块底 `#F1EFEA`；禁止冷灰蓝调背景 |
| C3 | 点缀色边界 | `#FF8A3D`（激励橙）/ `#FF9EB5`（腮红粉）仅限激励、彩蛋、贴纸类非功能元素，禁止进入操作色与状态色 |
| C4 | 控件规格 | 按钮高度 small 28 / default 36 / large 46，圆角 12px；间距遵循 8pt 栅格；pill（9999px）仅限五类场景：hero 双 CTA、消息发送、小白相关按钮、灵感 chips、弹层主确认 |
| C5 | AI 语义装饰 | sparkle ✦ 限定于「模型生成中 / 回答完成 / 溯源」时刻；品牌渐变 `#14B8A6→#3B82F6` 限定于 hero、小白身份、大标题徽标 |
| C6 | IP 情绪状态机 | 小白表情与页面状态一一映射：加载=打哈欠、成功=比心、超线=捂嘴、申诉=握拳、空态=摊手、思考=触角发光；源形象特征不可变形 |
| C7 | 文案规范 | 操作文案「说结果不说动作」；危险操作需情绪缓冲表述；禁用「尊敬的用户 / 请勿 / 您 / 提交 / 确认操作」等系统腔；信息量不得因口语化损失 |
| C8 | 可访问性 | 正文对比度 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1；当前基线：`#0F766E` 5.9:1、`#E5484D` 4.6:1；任何新增颜色须先验证对比度；全部动效（sparkle / spring / 呼吸）必须响应 `prefers-reduced-motion`；交互元素必须具备可聚焦样式（`:focus-visible` ≥ 2px 环） |

### 3. 优化任务

**T1 状态情绪完整性审查**
逐页检查五类状态（空 / 加载 / 成功 / 超线 / 失败）的视觉表达，输出「页面 × 状态」矩阵，标注缺失情绪陪伴或文案生硬的单元格并补齐方案。

**T2 场景化文案改写**
识别方案中残留的「功能说明书式」文案（如「查整篇 AI 率」），改写为用户场景语言（如「赶 DDL 前自查」）；改写后须保留可检索的关键信息词。

**T3 Hero 插画概念深化**
优化小白场景插画（小白指向论文高亮段落）的构图层次与生成 prompt；评估该视觉能否在三秒内传达「看得懂的检测报告」核心叙事；补充移动端降级方案。

**T4 游戏化微激励（限量）**
设计 ≤3 处微激励（如连续自查徽章、AI 率下降庆祝动效），每页 ≤1 处，不得干扰主流程；后台 Admin 界面完全排除。

**T5 移动端断点验证**
860px 断点下复核胖按钮、chips、表情图的布局与触控热区（≥44px）。

### 4. 反模式清单

- 禁止引入衬线字体、玻璃拟态滥用、大面积深色主题；
- 禁止引入第二主操作色（紫色系、通用「AI 蓝渐变」模板风）；
- 禁止 emoji 作为图标回潮（SparkLine 图标替换为硬验收项）；
- 禁止以牺牲信息密度换取可爱度（报告数值、表格必须保持一眼可读）；
- 禁止游戏化元素进入 Admin 后台。
